| 用途 | 取值 | 说明 |
|------|------|------|

## 2. 页面与组件设计

### 2.1 回放页控件浮层（FR-1）

现状控件栏为视频画面下方的独立布局条；本期改为**覆盖在视频画面底部的悬浮层**（移入 `.videoArea` 相对定位容器内），画面不再被挤压。

```
┌──────────────────────────────────────┐
│ 视频画面（16:9，.videoArea）           │
│        …… 弹幕浮层（现状不变）……        │
│                                      │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← 渐变遮罩（透明 → rgba(0,0,0,.7)）
│ ━━━━━━━━━━━━●━━━━━━━━━━━━━━━━━━━━━ │ ← 进度条贴浮层顶缘横贯
│ ▶  12:34 / 1:02:11  🔊──  1×  弹幕开 │ ← 控件行（单行）
│              [网页全屏]  [全屏]       │
└──────────────────────────────────────┘
```

- 控件行组成（现状全部控件保留）：播放/暂停、当前时间/总时长、音量（PC 滑杆 / 移动端仅静音切换）、倍速（0.5–2）、弹幕开关、**网页全屏**（新增，FR-5）、全屏。
- 显隐：播放中鼠标静止约 3 秒自动隐藏（沿用现有 `controlsIdle` 隐藏逻辑），移动鼠标/触摸重现；**暂停时常显**；隐藏为真正隐藏（`visibility: hidden`，不拦截画面点击）。
- 移动端（`< 48em`）：控件在浮层内换行收纳（进度条独占上缘一行、控件行允许折行），可触达且不超出画面边界。
- `:fullscreen`（原生全屏）下：`.videoArea` 撑满屏幕，浮层同样贴底，形态不变。

### 2.2 进度条 hover 时间预览（FR-3）

```
            ┌ 12:34 ┐              ← 时间预览（跟随指针，进度条上方）
━━━━━━━━━━━━━●━━━━━━━━━━━━━━━━━━  ← 进度条（鼠标 hover 未按下）
```

- 鼠标指针在进度条上移动（未按下）时，指针附近显示跟随的时间预览，内容为目标时间（`formatOffset` 格式，与现有时间显示一致，如 `12:34`）。
- 预览随指针位置**实时更新**；指针离开进度条立即隐藏。
- 与现有「按下拖动预览 + 松开提交 seek」并存互斥：拖动中（draft 值）优先显示拖动预览，hover 预览让位；拖动行为不变。
- 移动端无 hover：不显示该预览（不影响现有拖动预览）。

### 2.3 全屏切换与网页全屏（FR-4 / FR-5）

**FR-4 全屏切换（修复）**：

- 全屏按钮为**切换**行为：非全屏点击进入原生全屏；已全屏点击退出全屏。
- 按钮图标（SVG）与 `aria-label` / `aria-pressed` 随实际全屏状态同步（监听 `fullscreenchange`）；Esc 等浏览器原生退出路径后按钮恢复「进入全屏」态，不残留错误状态。

**FR-5 网页全屏（theater）**：

```
┌───────────────────────────────────────────────┐
│ ┌─────────────────────────────┬─────────────┐ │
│ │ （画面区，flex:1）            │ 事件列表     │ │
│ │                             │ 320–360px   │ │
│ │      ┌───────────────┐      │ ┌─────────┐ │ │
│ │      │  视频（16:9）   │      │ │ 00:12 … │ │ │
│ │      │ 垂直水平居中     │      │ │ 00:15 … │ │ │
│ │      └───────────────┘      │ │ ……      │ │ │
│ │        [控件浮层 FR-1]       │ │（全高滚动）│ │ │
│ └─────────────────────────────┴─────────────┘ │
└───────────────────────────────────────────────┘
         ↑ 舞台 fixed 占满浏览器可视区域
```

- 控件行新增「网页全屏」按钮（`IconTheater`，与全屏图标可区分，`aria-pressed`）。
- 进入后：回放舞台占满浏览器可视区域（`position: fixed; inset: 0`，层级高于页头）；**右侧为事件列表（弹幕信息流），左侧为视频画面**；画面在左侧容器内**垂直水平居中**（而非顶部对齐），保持 16:9 比例、尽可能大地适配剩余空间（flex 居中 + `aspect-ratio: 16/9` + 最大宽高约束）。
- 播放控件仍悬浮于画面之上（FR-1 形态不变）。
- 再次点击「网页全屏」按钮恢复原页面布局。
- 与浏览器全屏互斥：进入浏览器全屏时自动退出网页全屏态并**记住**该状态；退出浏览器全屏后恢复进入前状态。网页全屏开启时点击全屏按钮 = 暂退网页全屏并进入浏览器全屏。
- 移动端（`< 48em`）：**不提供**网页全屏入口（按钮 CSS 隐藏，同移动端隐藏音量滑杆做法），保持现有上下布局。

### 2.4 弹幕列表信息流（FR-6）

事件列表整体从「单行纯文本」改为**信息流模式**；每条事件保留**时间戳**（左侧固定宽列，`mm:ss`）与**点击跳转（seek）**能力，当前条目高亮、自动跟随/「回到底部跟随」等行为不变（现状保留）。

**FR-6.1 弹幕（inline，支持换行）：**

```
┌────────────────────────────────────────────┐
│ 00:12 [牌] 用户名：这是弹幕内容，可以换行     │
│        混排表情 😀（图片）与文字              │
└────────────────────────────────────────────┘
   ↑ 时间戳   ↑ 粉丝牌 badge   ↑ 浅色用户名
```

- 依次为「粉丝牌 badge（牌名 + 等级，`medal.color` 着色）」「用户名（浅色）」「冒号」「用户发言」，inline 流式布局、自然换行。
- 发言支持文字与表情包：`emote` 渲染为 `<img>` 图文混排（固定行内高度、`loading="lazy"` 懒加载）。
- 无 medal 时省略 badge 段，其余不变。

**FR-6.2 礼物（gift / gift_v2，inline，支持换行）：**

```
│ 00:20 [牌] 用户名 赠送了 [礼物图标] 人气票 ×1  ¥0.10 │
```

- 发送者展示沿用 6.1 的粉丝牌/用户名样式；礼物信息：礼物图标（图片，懒加载）、礼物名 × 数量、金额（`price > 0` 时显示，前置 `¥`）。
- `gift_v2` 事件经解析层归一为 `gift` 后共用同一展示结构（需求 §7 API 调研结论），样式无差异。

**FR-6.3 舰长上舰（guard_buy，独占一行卡片）：**

```
┌────────────────────────────────────────────┐
│ ▌ 00:35  用户名 开通了 舰长 ×1    ¥198.00    │  ← 左边框 3px 金 + 底 night287-8
└────────────────────────────────────────────┘
```

- **独占一行**的醒目卡片，与普通弹幕明显区分（底色 + 左边框）。
- 内容：「用户名 开通了 {guard.name}（舰长/提督/总督）×{count}」+ 金额（如有）。
- 上游事实：guard_buy 无头像、无粉丝牌（`face`/`medal` 恒空），不渲染对应元素。

**FR-6.4 醒目留言 SC（super_chat，独占一行卡片）：**

```
┌────────────────────────────────────────────┐
│ 00:41  用户名                       ¥50.00  │  ← scColors 渐变背景
│ SC 留言内容（支持多行）                       │  ← fontColor 文字
└────────────────────────────────────────────┘
```

- **独占一行**的醒目卡片；卡片配色使用接口返回的 `scColors`（背景 `backgroundStart → backgroundEnd` 渐变 + 文字 `fontColor`），缺失/非法时回退 §1 默认金色系配色。
- 内容：用户名、SC 留言内容（可多行）、金额（如有）。

### 2.5 历史录播条目「播放/下载」按钮组（FR-2）

```
┌──────────────────────────────────────────────┐
│ 游玩饥荒                          [▶ 播放 ▾] │  ← 标题区（Link）+ 右侧按钮组
│ 2026-09-23 14:59 · 3小时22分 · 9.0GB          │
└──────────────────────────────────────────────┘
                                 ▾ 点击展开
                                 ┌────────────┐
                                 │ ⬇ 下载      │  ← 下拉菜单项（SVG 图标）
                                 └────────────┘
```

- 条目拆为两部分：标题/元信息区保留 `<Link>`（点击进站内回放页，行为不变）；右侧新增按钮组——主按钮「**播放**」+ 箭头按钮。
- 「播放」跳站内回放页（与条目本体同址）；点击箭头展开下拉菜单，含「**下载**」项（`IconDownload` SVG 图标 + 文字），点击后浏览器直接下载录播 FLV 直链（`<a href download>` 触发，不经本站中转）。
- 下拉开合：点击箭头切换；点击外部 / Esc 关闭（简单焦点管理，不引库）。
- 按钮组不破坏现有布局：条目行内右侧对齐、窄屏可收缩（主按钮文字可缩为图标 + aria-label），移动端可操作。
- 图标一律 SVG（R14-5 口径）：`IconPlay`（既有）+ 新增 `IconDownload`。

## 3. 交互说明

| 交互 | 触发 | 反馈 |
|------|------|------|
| 控件显隐 | 播放中静止约 3s / 移动鼠标·触摸 / 暂停 | 自动隐藏（真正隐藏）→ 重现；暂停时常显 |
| 进度条 hover 预览 | 鼠标在进度条上移动（未按下） | 指针附近显示目标时间，实时更新；离开即隐藏 |
| 进度条拖动 | 按下拖动 / 松开 | 拖动中显示 draft 预览（与 hover 互斥）；松开提交 seek（现状不变） |
| 全屏切换 | 点击全屏按钮 | 进入/退出原生全屏；图标与 `aria-pressed` 同步；Esc 退出后按钮恢复 |
| 网页全屏切换 | 点击「网页全屏」按钮 | 舞台占满可视区（左画面居中 / 右列表）；再次点击恢复；与浏览器全屏互斥 |
| 播放/下载按钮组 | 点击「播放」/ 箭头 | 进回放页 / 展开下拉（含「下载」）；点外部或 Esc 收起 |
| 下载 | 点击「下载」项 | 浏览器直链下载 FLV（跨源时可能转为打开/播放，见技术方案 §5 风险 #2，属可接受行为） |
| 事件条目点击 | 点击任一条目（含卡片） | seek 到对应时间（现状不变） |
| 事件列表跟随 | 播放推进 / 手动滚动 | 自动跟随高亮；手动滚动暂停跟随 +「回到底部跟随」按钮（现状不变） |

**状态清单**：控件浮层（常显 / 隐藏 / 暂停常显）、进度预览（无 / hover 预览 / 拖动 draft）、全屏按钮（进入态 / 退出态）、网页全屏（关 / 开 / 被浏览器全屏暂退记忆）、按钮组（收起 / 展开）、信息流条目（弹幕 / 礼物 / 舰长卡 / SC 卡 / 当前高亮）。

**可访问性**：全屏与网页全屏按钮有明确 `aria-label` 与 `aria-pressed`；新增交互（下拉菜单、网页全屏）可键盘操作（按钮原生可聚焦，Esc 关闭菜单）；卡片配色不以颜色为唯一信息通道（保留文字类型标识）。

**性能**：信息流沿用窗口化渲染（当前 ± 相邻 10 分钟，逐窗增量），不全量挂载长录播事件；礼物图标/表情图片 `loading="lazy"`。

**降级**：MSE 不支持降级文案、iOS 降级提示行为不变（沿用录播模块设计 §2.5）。
