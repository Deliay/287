## 1. 色彩系统

### 1.6 落地方式

- 五套色阶注册为 Mantine 自定义颜色（`theme.colors`），全局只引用 token，不硬编码色值。

## 2. 布局与页面结构

### 2.1 断点

- 移动端：`< 48em`（768px，Mantine `sm` 断点以下）
- PC 端：`≥ 48em`

### 2.2 页面结构（自上而下）

```
┌──────────────────────────────┐
│ 导航栏（固定顶部，高 60px）      │
├──────────────────────────────┤
│ 首屏：成员立绘墙（100dvh）       │
├───────────┬──────────────────┤
│ 介绍区 1：小松绿（≥100dvh）      │
├───────────┼──────────────────┤
│ 介绍区 2：四时小路               │
├───────────┼──────────────────┤
│ 介绍区 3：羽啾                   │
├───────────┼──────────────────┤
│ 介绍区 4：枝堇                   │
└───────────┴──────────────────┘
```

### 2.3 导航栏

- 高度 60px，固定顶部，背景 `#2e2b38`（287-8）+ 轻微透明/模糊，底部分隔线 `#454154`（287-7）。
- 左侧：站点名「287 应援站」（287-0 文字）。
- PC 端：导航项**右对齐**，当前仅「首页」，点击平滑滚动回页面顶部；文字 287-1，hover 287-0。
- 移动端：右侧为汉堡按钮，点击打开全宽抽屉（Drawer，自右侧滑出），抽屉内纵向列出导航项「首页」；点击导航项或遮罩关闭抽屉。
- 导航栏层级最高，滚动时不遮挡首屏立绘的面部区域（首屏立绘的构图以上半身为准，顶部预留导航栏高度的安全区）。

### 2.4 首屏 · 成员立绘墙

**顺序（官方海报「绿黑白紫」）：** 小松绿 → 四时小路 → 羽啾 → 枝堇。

**PC 端：**

```
┌─────────┬─────────┬─────────┬─────────┐
│         │         │         │         │
│ 小松绿   │ 四时小路 │  羽啾   │  枝堇   │  ← 各 25vw，高 100dvh
│ (立绘上半身)│        │         │         │
│         │         │         │         │
└─────────┴─────────┴─────────┴─────────┘
```

- 四列并排，各 `25vw`，整体高 `100dvh`，宽度占满无间隙。
- 立绘使用 `resources/*.avif`，以 `object-fit: cover` + 定位到顶部裁切出**上半身**；各列底部叠成员名称（中文名 + 罗马音）与代表色指示条（成员调色盘 index 6，高 4px）。
- **Hover 态（仅 PC）**：
  - 当前列：正常色彩，立绘轻微放大（`scale(1.03)`）并提亮；
  - 其余三列：`filter: grayscale(1) brightness(0.6)`；
  - 过渡 300ms ease-out；鼠标移出首屏区域后全部恢复。
- **点击**：新标签页打开该成员 B 站主页（`target="_blank" rel="noopener noreferrer"`）；四位成员的 UID 直链见[需求文档 §7](../requirement/2026-09-23-fan-site-phase-1.md)。

**移动端：**

```
┌──────────────────┐
│ 小松绿（立绘上半身） │  ← 各高 25dvh，
├──────────────────┤    宽 100%，
│ 四时小路           │    顺序同 PC
├──────────────────┤
│ 羽啾              │
├──────────────────┤
│ 枝堇              │
└──────────────────┘
```

- 四行纵向排列，各 `25dvh`，横向占满；立绘同样裁切上半身，成员名称与代表色指示条位置与 PC 一致。
- 无 hover 态，点击行为同 PC。

### 2.5 成员介绍区

四个介绍区顺序与首屏一致（绿黑白紫），每区最小高度 `100dvh`。

**PC 端（左立绘、右介绍）：**

```
┌────────────┬───────────────────┐
│            │  成员名（成员色强调）  │
│  立绘半身   │  身份 / 称号         │
│  （左侧）   │  简介段落            │
│            │  [前往 B 站主页 →]   │
└────────────┴───────────────────┘
```

- 左列宽约 40%，立绘为**半身**裁切，底部对齐区块下缘；右列宽约 60%，内容垂直居中，最大行宽 36em。
- 背景：287-9 与 287-8 交替（奇数区 287-9，偶数区 287-8），区块内以成员调色盘做标题色（index 视对比度取 1–3 浅阶）与按钮/链接强调色（index 5–6）。

**移动端（纵向布局）：**

```
┌──────────────────┐
│   立绘半身（上方）   │
│   高约 50dvh       │
├──────────────────┤
│ 成员名 / 身份       │
│ 简介段落            │
│ [前往 B 站主页 →]   │
└──────────────────┘
```

- 立绘在上、介绍在下，介绍区左右留白 16px。

## 3. 交互说明

| 交互 | 触发 | 反馈 |
|------|------|------|
| 阻尼滚动 | 鼠标滚轮 / 触控板 / 触屏滑动 | 滚动速度经阻尼曲线平滑处理（缓出惯性），无跳跃感；实现选型（如 lenis 等）留待技术方案阶段 |
| 立绘 hover | PC 鼠标悬停某列 | 该列高亮放大，其余变灰，300ms ease-out 过渡 |
| 立绘点击 | 点击列/行 | 新标签页打开对应成员 B 站主页 |
| 导航「首页」 | 点击 | 平滑滚动回页面顶部 |
| 移动端菜单 | 点击汉堡按钮 | Drawer 自右滑出；点击遮罩/关闭按钮/导航项后收起 |
| 图片加载中 | 立绘加载未完成 | 以成员调色盘 index 8 深色占位，避免白闪 |
| 图片加载失败 | avif 加载失败 | 显示成员调色盘 index 8 底色 + 成员名称文字兜底 |

**状态说明**：本期无后端数据，无业务空态/错误态；导航栏菜单开关、hover 高亮为仅有的组件状态。
