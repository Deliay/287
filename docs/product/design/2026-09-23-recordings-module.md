## 1. 设计原则与色彩

- 沿用一期建立的色彩系统（[一期设计文档 §1](./2026-09-23-fan-site-phase-1.md)）：页面全局使用「287」深色基调（背景 287-9 `#1c1a22`，卡片 287-7 `#454154`，主文字 287-0，次要文字 287-2），成员相关内容使用该成员调色盘作强调。
- 成员卡片的强调方式统一为：**顶部 4px 指示条 + 成员名标题色**（成员调色盘 index 6，chu2u 等高明度色在深色背景上取 index 2–3 浅阶保证对比度）。
- 状态语义色：直播中 = 成员色（点亮）；未开播 = 287-4 灰；加载中 = 287-3 骨架；错误 = komichi-6 `#ff2231`（仅错误文本/图标，不大面积使用）。
- 断点沿用：移动端 `< 48em`，PC 端 `≥ 48em`。

## 2. 页面结构

### 2.1 导航栏变更

- 导航项从「首页」一项增加为「首页」「录播」两项，顺序：首页 → 录播。
- PC 端右对齐不变；移动端折叠进汉堡抽屉，纵向排列。
- 当前所在页面对应导航项以下划线/加亮（成员色无关，用 287-0 文字 + 287-6 指示条）标识。

│ ├───────────┼───────────┤      │     移动端纵向单列

### 2.3 直播状态卡片（FR-2 / FR-3）

```
┌──────────────────────┐
│ ▮（成员色指示条 4px）   │
│ 小松绿 Viridis  ●直播中 │  ← 成员名（成员色）+ 状态徽标
│ 重生之我是钓鱼大师      │  ← 直播标题，未开播时不显示
│ 更新于 21:58           │
│ [ ▸ 听直播 ]           │  ← 仅「直播中」时可点
└──────────────────────┘
```

- 卡片顺序固定绿黑白紫（小松绿 → 四时小路 → 羽啾 → 枝堇），与首页一致。
- 状态徽标：「直播中」为成员色圆点 + 文字（圆点带 1.5s 呼吸动效）；「未开播」为灰点 + 文字。徽标均含文字，不以颜色为唯一信息通道。
- 卡片四角：PC 2×2 网格（间距 16px），移动端单列（间距 12px），位于录播页首屏。
- 「听直播」按钮：未开播时禁用并置灰；收听中变为「■ 停止收听」（成员色填充 → 边框态切换）；加载中显示 spinner。
- 卡片点击（按钮以外区域）：滚动定位到下方对应成员的录播分组并展开。

### 2.4 历史录播列表（FR-4，后加载）

- 位于状态卡片下方，按成员分组；分组头左侧为成员色小方块 + 成员名，右侧为展开/收起箭头与（已加载时的）条目数。
- **后加载表现**：分组折叠态不请求数据；首次展开或分组头进入视口时触发加载，加载中显示 3 行骨架条。
- 录播条目：

```
┌────────────────────────────────┐
│ 游玩饥荒                        │  ← info.title（缺失时回退文件名）
│ 2026-09-23 14:59 · 3小时22分 · 9.0GB │
└────────────────────────────────┘
```

- 条目间以 287-7 分隔线隔开；hover（PC）背景提亮为 287-8；点击进入站内回放页。
- 分页：每组每页 20 条，底部「上一页 / 下一页」+ 页码。
- 空态：该成员暂无录播时显示「暂无录播」+ 成员色图标，不显示分页。
- 错误态：「加载失败」+「重试」按钮，仅影响该分组。

### 2.5 回放页 `/recordings/replay`（FR-5）

**PC 端：**

```
┌─────────────────────────────────────────┐
│ ← 返回录播列表   游玩饥荒 · 枝堇 Sumire    │  ← 页头：返回 + 标题 + 成员
├──────────────────────────────┬──────────┤
│                              │ 事件列表  │
│   视频区（16:9，含弹幕浮层）    │ （时间线）│  ← 视频 4/5 宽，
│                              │          │     列表 1/5 宽
├──────────────────────────────┤          │
│ 控件栏：▶ 进度条 音量 倍速 全屏 │          │
└──────────────────────────────┴──────────┘
```

**移动端：**

```
┌──────────────────┐
│ ← 返回  标题      │
├──────────────────┤
│ 视频区（16:9）    │
│ 控件栏            │
├──────────────────┤
│ 事件列表          │
│ （剩余高度滚动）   │
└──────────────────┘
```

- **播放控件**（视频区底部悬浮栏，静止 3s 自动隐藏，移动鼠标/触摸重现）：播放/暂停、进度条（已播放=成员色，已缓冲=287-5，未加载=287-7）、当前时间/总时长、音量（PC 为滑杆，移动端仅静音切换）、倍速（0.5/1/1.25/1.5/2）、全屏。
- **seek**：拖动进度条松开后开始 seek；seek 中视频区中央显示加载 spinner，控件栏进度暂时锁定；失败时视频区中央显示错误文案 + 「重试」。
- **弹幕浮层**：视频区上层，从右向左匀速横穿，多轨道不重叠；表情弹幕以图片渲染。控件栏含弹幕开关。播放头跳变 **|Δt| > 2 秒** 判定为 seek 并清空重建（2026-09-24 补注，与实现一致）；事件列表渲染范围为已加载窗口（当前 ± 相邻 10 分钟），逐窗增量加载（同日勘误，见 §6-4 关联的 PRD 勘误）。
- **事件列表**：每行显示相对时间（mm:ss）、发送者名、内容（SC/礼物/舰长带类型徽标）；随播放自动滚动跟随并高亮当前时间附近条目；用户手动滚动后暂停跟随，出现「回到底部跟随」浮动按钮；点击条目 seek 到对应时间点。
- **降级**：浏览器不支持 MSE 时，视频区替换为「当前浏览器无法播放，请使用最新版 Chrome / Edge / Safari」提示。

### 2.6 悬浮播放组件（FR-6）

**展开态（PC 右下角，移动端底部全宽）：**

```
┌──────────────────────────────┐
│ 正在收听（2路）            ─ ▢ │  ← 标题栏：收起按钮
│ ▮小松绿    ♪────  🔊──  ✕   │  ← 每路：成员色块+名 / 状态 / 音量 / 停止
│ ▮枝堇      加载中…       ✕   │
│ [ 全部停止 ]                  │
└──────────────────────────────┘
```

**收起态（迷你条）：**

```
┌──────────────────┐
│ ♪ 在听 2 路    ▢ │
└──────────────────┘
```

- 出现时机：存在至少一路进行中的「听直播」；全部停止后自动消失。
- 位置：PC 右下角悬浮（距右/下 24px，宽 320px）；移动端底部全宽贴边，适配底部安全区；层级低于导航抽屉遮罩、高于页面内容。
- 每路状态：播放中（波形动效）、加载中（spinner）、失败（红色「失败」+ 重试图标）；点击成员名跳回 `/recordings`。
- 跨页面：路由切换组件不卸载、音频不中断（视觉上线条无变化，仅路径切换）。

## 3. 交互说明

| 交互 | 触发 | 反馈 |
|------|------|------|
| 导航「录播」 | 点击导航项 / 抽屉项 | 跳转 `/recordings`，导航项加亮 |
| 状态轮询 | 每 30s | 卡片数据静默更新；状态变化时徽标即时切换，无闪烁 |
| 听直播 | 点击「▸ 听直播」 | 按钮转加载态 → 播放中转「■ 停止收听」；悬浮组件出现/新增一路 |
| 停止收听 | 卡片按钮或悬浮组件 ✕ | 该路停止，悬浮组件移除该路；0 路时组件消失 |
| 单路失败 | 流断开/网络错误 | 该路标失败态 + 重试入口（悬浮组件与卡片同步），其他路不受影响 |
| 录播分组展开 | 点击分组头 / 进入视口 | 首次触发加载（骨架屏），成功后展开列表 |
| 录播条目点击 | 点击条目 | 站内跳转 `/recordings/replay?roomId=…&file=…` |
| seek | 拖动进度条松开 | 中央 spinner → 续播；弹幕浮层清空重建；事件列表跳至新时间点 |
| 事件条目点击 | 点击列表条目 | seek 到该事件时间点 |
| 全屏 | 点击全屏按钮 | 视频区进入原生全屏，控件与弹幕浮层保留 |
| 悬浮组件收起/展开 | 点击 ─ / ▢ | 展开态 ↔ 迷你条互切，播放不受影响 |
| 接口失败 | 状态/录播/弹幕请求失败 | 对应区域错误文案 + 重试；其余区域不受影响，不白屏 |

**状态清单**：卡片（直播中 / 未开播 / 加载中 / 失败）、录播分组（未加载 / 加载中 / 成功 / 空 / 失败）、回放页（加载中 / 播放中 / seek 中 / 播放失败 / MSE 不支持降级）、悬浮组件（隐藏 / 迷你条 / 展开）。

## 6. 实现勘误与 Review 留痕（2026-09-24 · 次-2）

审核要求「逐项对齐 **或** 回写勘误（不得静默偏离）」——本节对七项视觉规格差异逐条回写口径，**均按现有实现确认，未静默偏离**：

1. **「直播中」圆点**：实现为状态文字同色圆点（night287-0），非成员色。勘误：§2.3 圆点改述为「与状态文字同色，成员色强调由顶部 4px 指示条 + 成员名承担」（避免圆点与指示条重复编码同一信息）。
2. **「听直播/停止收听」按钮**：实现为 night287 描边 + 收听态 night287-6 填充。勘误：§2.3 改述为「常态 night287 描边、收听中 night287-6 填充」；成员色填充方案延后到视觉迭代（四卡同时大面积成员色会削弱 287 深底层次与状态语义对比）。
3. **成员强调色取阶**：实现统一取 index 6。勘误：统一口径为——深底**文字**取浅阶 0–2（chu2u 亦然，theme.ts 注释同步），**强调色块/名色**取 index 6（chu2u-6 `#d4da7b` 在 287-9 上对比充足）；§1 原「2–3 浅阶」专指文字场景，按此口径理解，`theme.ts` 注释已同步为同一表述。
4. **加载中/失败/重试表达**：实现以文字态（「加载中…」「失败」「缓冲中…」）+ 骨架屏承载，未用 spinner/波形/图标。勘误：§2.3/§2.6/§2.5 补注「加载/失败态允许以文字 + 骨架等价表达（可访问性同级），图标为后续视觉迭代项」。
5. **录播空态**：实现为纯文字「暂无录播」，无成员色图标。勘误：§2.4 空态改述为「文字空态（成员色方块已在分组头体现，空态不重复编码）」。
6. **回放控件栏**：实现为视频区下方独立条（非视频区底部悬浮层），静止隐藏后仍占位。勘误：§2.5 改述为「控件栏为视频区下方独立条；静止 3s 后以 `visibility:hidden` 隐藏但仍占位（避免布局跳动），鼠标/触摸重现」。
7. **色彩 token**：实现卡片底 287-8、未开播灰点 287-5、骨架 287-7/287-6。勘误：**以本条列出的实现值为准**，§1/§2.3/§2.4 中相应原值（卡片 287-7、未开播灰 287-4、骨架 287-3）不再适用；原文「卡片 287-7 与 hover 提亮 287-8」自相矛盾，按**提亮语义**保留实现（常态 287-8，页面底 287-9 层次更清）。
