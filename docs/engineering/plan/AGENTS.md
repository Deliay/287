# 技术实现方案（plan）规范

本目录存放技术实现计划文档，是开发前置流程的**第五阶段**产出物，是开发执行前的最后一步。

## 何时编写

对应主题的技术方案（`../proposal/`）通过评审后，才开始本阶段。

## 文档必须包含的内容

1. **对应技术方案**：引用 `../proposal/` 中的同名主题文档。
2. **任务拆解**：将实现拆分为可独立执行、可验证的小任务，每个任务标注涉及的文件路径。
3. **TDD 测试计划**：每个任务对应的测试用例清单，遵循根目录 `AGENTS.md` 中的红-绿-重构流程：
   - 红：先写失败的单元测试（描述目标行为）；
   - 绿：写最小实现使测试通过；
   - 重构：测试保持绿色的前提下改进代码。
4. **执行顺序与依赖**：任务之间的先后关系。
5. **验收对照**：每项任务完成后如何对照需求文档的验收标准进行验证。

## 完成条件（DoD）

- 任务拆解粒度足够小（单个任务可在数小时内完成）。
- 每个任务都有对应的测试计划。
- 本文档完成后，方可开始编码。

## 注意事项

- 开发过程中如任务需要调整，先更新本文档再继续编码。
- 每个任务完成后在文档中勾选/标记，保持计划与实际进度一致。
- 文档命名遵循 `../AGENTS.md` 中的通用约定，主题名与上游文档保持一致。
